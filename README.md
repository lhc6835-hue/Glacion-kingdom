# Axenfall — 그늘진 계곡의 벌목꾼

픽셀 아트 2D 횡스크롤 게임입니다. 나무를 타이밍에 맞춰 찍고, 목재를 팔거나 가공하고, 도끼를 모으고, 클래스를 사서 성장합니다.
브라우저에서 바로 돌아가고, 그림과 소리는 전부 코드로 그리고 합성합니다. 외부 에셋 사이트는 이 개발 환경에서 접속이 막혀 있었습니다([docs/ASSETS.md](docs/ASSETS.md) 참고).

- **분위기**: 맑고 산뜻한 숲 대신, 서늘하고 그늘진 계곡 숲입니다. 청록 그림자, 이끼 바위, 시냇물이 있고, 수관 틈으로 따뜻한 빛줄기가 떨어집니다
- **핵심 반복**: 탐험 → 나무 발견 → 타이밍 공격 → 목재 → 판매 또는 가공 → 도끼와 클래스 → 더 단단하고 희귀한 나무

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist/ 에 정적 빌드
npm test           # 로직 테스트 + 빌드된 게임을 헤드리스 브라우저로 실제 플레이 (먼저 npm run build)
npm run balance    # 경제 시뮬레이션 (node tests/balance.mjs [분] [casual|average|expert])
```

URL 옵션: `?play`는 시작 화면을 건너뜁니다. `?t=19`는 시작 시각, `?q=low|medium|high`는 그래픽 품질입니다.
`node tools/artifact.mjs out.html`을 실행하면 CSS와 JS가 모두 들어간 단일 HTML 파일을 만듭니다.

## 조작

| 키 | 동작 |
|---|---|
| A D / ← → | 이동 (Shift 달리기) |
| Space | 점프 (짧게 누르면 낮게) |
| 클릭 / J | 나무 앞에서 벌목 시작, 이후 클릭마다 타격 |
| Q | 클래스 기술 |
| E | 상호작용 (상인, 제단, 길드, 제재소, 고목) |
| I / C / Esc | 가방 / 도감 / 설정·닫기 |

휴대폰과 태블릿에서는 화면에 ◀ ▶, 점프, 도끼, E, 기술 버튼이 나옵니다. 가로 화면을 권장합니다.

## 아직 없는 것

- 2번째 이후 지역(해비침 숲 등 11곳), 지역 이동과 발견 연출
- 적대 생물, 전투형 잡몹, 보스
- 퀘스트와 NPC 대화, 스토리 진행. 지금은 목표 안내와 세계 기록 몇 줄만 있음
- 제재소 6~10단계, 자동화, 복수 가공소
- 클래스 5종 이상, 날씨
- 외부 에셋(네트워크 정책으로 막힘). 모든 그래픽과 소리는 코드로 만든 결과물이라 손그림 에셋으로 바꿀 여지가 있음
