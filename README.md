# 글래시온 왕국 — 깃털족의 노래

동글동글한 새, **깃털족**이 사는 판타지 왕국을 자유롭게 탐험하는 HD-2D 오픈월드 RPG입니다.
브라우저에서 바로 실행되며, 모든 그림과 소리는 외부 에셋 없이 코드로 직접 그리고 합성합니다.

- 위에서 내려다보는 2D 시점이지만, 화면 위쪽에는 **실제 지평선**이 있어 하늘, 먼 설산, 호수 너머 왕성이 보입니다
- 보이는 곳은 실제로 갈 수 있습니다. 햇살 언덕에서 출발해 호숫가를 돌아 왕의 길 오르막을 지나 남문으로 들어가면 왕도가 나옵니다
- 높은 곳에서 뛰어내려 Space를 누르고 있으면 활공합니다. 절벽 위 왕성 정문에서 호수까지 날아갈 수 있습니다

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist/ 에 정적 빌드
npm run preview    # 빌드 결과 미리보기
npm test           # 빌드된 게임을 헤드리스 브라우저로 실행해 자동 점검 (먼저 npm run build)
```

URL 옵션: `?play` 타이틀 건너뛰기 · `?t=19` 시작 시각 지정 · `?lowres` 저해상도 렌더링

## 조작

| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 |
| Shift | 달리기 |
| Space | 깡총 점프 · 공중에서 누르고 있으면 활공 |
| E | 대화 · 살펴보기 · 줍기 |
| Q | 모험 일지 (의뢰 추적) |
| M | 지도 |
| 마우스 휠 | 확대 / 축소 |
| T | 시간 빠르게 흐르게 하기 |
| Esc | 창 닫기 |

모바일에서는 화면 왼쪽을 드래그해 이동하고, 오른쪽을 탭하면 점프하거나 상호작용합니다.
