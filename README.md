# MELTDOWN — Last Scoop Standing

주인공이 **아이스크림**인 웨이브 생존 게임입니다. 몰려오는 더위(열기방울, 불씨, 햇살 정령…)를 막으면서 최대한 오래 버티세요.
쌓아 올린 **스쿱 한 층이 곧 목숨**이에요. 맞으면 맨 위 층부터 녹아 떨어지고, 그 층의 맛 특성도 함께 사라집니다.

브라우저에서 바로 실행됩니다. 그림과 소리는 외부 에셋 없이 모두 코드로 그리고 합성해요.

## 게임 구성

| 영역 | 내용 |
|---|---|
| 캐릭터 | 틀 + 층마다 다른 맛 + 표정. 층마다 스프링으로 따로 흔들려서 쫀득하게 출렁여요. 눈은 항상 가운데로 모인 점 두 개, 입은 단순한 선이에요 |
| 틀 (26종) | 틀마다 층 수(1~5층)와 고유 특성이 달라요. 예: 터키 아이스크림 콘은 50% 확률로 공격을 회피하고, 기본 아이스크림 콘(OG)은 한 판에 한 번 모든 층을 되살려요 |
| 맛 (56종) | 맛마다 특성이 있어요. 맨 위 층은 100%, 아래층으로 갈수록 75 · 60 · 50 · 42%로 효과가 줄어요. 바닐라와 초코는 최고 등급(OG)이에요 |
| 무기 (17종) | 숟가락 3연타, 초코칩 연사, 스프링클 샷건, 콘 부메랑, 아이스바 창, 젤리 블래스터, 체리 폭탄, 시럽 채찍, 휘핑크림 분사, 막대사탕 해머, 탄산 레이저, 지팡이사탕 활, 솜사탕 구름, 스쿱 런처, 오로라 리본, 은하 마카롱, 황금 원조 숟가락. 무기마다 공격 방식과 모션이 모두 달라요 |
| 등급 (10단계) | 얼음조각 → 소프트 → 스쿱 → 스프링클 → 젤라또 → 선데 → 빙하 → 오로라 → 갤럭시 → OG. 틀 가격은 180에서 1,000,000코인까지 차이가 나요 |
| 표정 (20종) | 광장의 표정 가게에서 사요 |
| 웨이브 | 무한 웨이브예요. 5웨이브마다 보스(이글이글 태양, 용암 슬라임 킹, 아지랑이 여왕)가 나오고, 웨이브가 끝날 때마다 토핑(인게임 강화)을 3개 중 하나 골라요 |
| 성장 | 계정 레벨과 경험치가 있고, 레벨이 오를 때마다 보너스 코인을 받아요. 같은 맛이나 무기를 또 뽑으면 레벨이 올라요(최대 10) |
| 광장 (위에서 보는 시점) | 가운데에 3단 아이스크림 분수대가 있고, 다른 플레이어가 실시간으로 보이고 채팅도 돼요. 틀 갤러리 입구, 맛 뽑기, 무기 뽑기, 오늘의 게시판(맛 투표, 랭킹, 소식), 소원의 분수대, 표정 가게, 벤치, 플레이 존이 있어요 |
| 틀 갤러리 | 5층짜리 건물이에요. 층마다 틀 실루엣이 일렬로 놓여 있고, 가까이 가서 상호작용하면 구매 창이 떠요. 엘리베이터로 층을 옮겨 다녀요 |
| 플레이 존 | 방 이름과 인원(1~4명)을 정해 방을 만들어요. 공개 방 목록이나 6자리 코드로 들어갈 수 있어요 |
| 계정 | 아이디와 비밀번호로 로그인하거나 회원가입해요. 게스트로 하면 기록은 그 기기에만 저장돼요 |

## 조작

| PC | 모바일 |

| WASD 이동 · 마우스 조준 · 좌클릭 공격 · 스페이스/우클릭 구르기 | 왼쪽 스틱 이동 · 오른쪽 스틱 조준하면서 공격 · 구르기 버튼 |
| 광장: WASD 이동, E 상호작용, T 채팅 | 광장: 왼쪽 스틱, 대화 버튼 |

## 개발

```bash
npm install
npm run dev        # http://localhost:5173 (로컬 개발 중에도 온라인 서버에 접속)
npm run build && npm test   # 빌드한 게임을 헤드리스 브라우저로 자동 점검
```

URL 옵션: `?offline` 서버 없이 게스트로 · `?plaza` 광장 바로 가기 · `?shop=0..4` 틀 갤러리 층 · `?play&w=무기&m=틀&f=맛1,맛2&wave=5` 원하는 조합으로 바로 전투.
`art.html`(개발 서버 전용)은 모든 틀(`?m=molds`), 맛(`?m=flavors`), 표정(`?m=faces`), 적(`?m=enemies`)을 한 화면에 그려서 보여줘요.

배포:

```bash
NODE_USE_ENV_PROXY=1 node tools/deploy-worker.mjs   # 게임 페이지와 서버를 Cloudflare Workers에 올림
tools/deploy-pages.sh                               # GitHub Pages(gh-pages 브랜치)에 정적 빌드 올림
```

## 구조

```
shared/      클라이언트와 서버가 함께 쓰는 데이터와 규칙 (등급, 틀, 맛, 무기, 표정, 경제)
src/core/    루프 보조, 입력(키보드·마우스·터치 스틱), 스프링, 사운드 합성, 프로필
src/render/  스쿱·틀·표정·적 그림(하나의 실루엣 + 외곽선으로 굽기), 전투 섬 배경
src/game/    전투: 스탯 계산, 플레이어, 무기 17종, 적 AI와 보스, 웨이브, 이펙트
src/scenes/  타이틀(로그인), 광장, 틀 갤러리, 전투 장면
src/ui/      DOM 메뉴: 토핑 선택, 결과, 꾸미기, 뽑기, 표정 가게, 게시판, 플레이 존, 대기실
src/net/     서버 API, 광장 동기화, 협동(방장이 적을 계산하고 각자 자기 피해를 방장에게 보냄)
server/      Cloudflare Worker + Durable Objects (Store: 계정·투표·랭킹·방 목록, Plaza, Room)
```
