# 에셋 현황

## 외부 에셋 조사 결과

무료 에셋을 먼저 쓰려고 했지만, 이 개발 환경의 네트워크 정책이 다음 사이트 접속을 막았습니다(프록시가 CONNECT 요청에 403 응답).

| 사이트 | 결과 |
|---|---|
| kenney.nl | 차단 |
| opengameart.org | 차단 |
| itch.io | 차단 |
| freesound.org | 차단 |
| cdn.jsdelivr.net | 차단 |
| GitHub 검색 API | 이 세션에 연결된 저장소 밖은 조회 불가 |

그래서 **외부 에셋은 하나도 받지 않았고, 프로젝트에 외부 파일도 없습니다**. 라이선스를 확인할 대상도 없습니다.
환경 설정의 Network access에 위 도메인을 추가하면 다음 작업에서 실제로 받아서 통합할 수 있습니다(https://code.claude.com/docs/en/cloud-environments#network-access).

## 지금 쓰는 리소스 (모두 코드로 생성, 이 저장소의 저작물)

| 리소스 | 생성 위치 | 상태 |
|---|---|---|
| 나무 5종(개체마다 시드 변형, 수관 3~4조각) | `src/art/trees.js` | 최종 품질에 가까움. 손그림 에셋으로 바꿀 수 있음 |
| 주인공(부위별 실시간 드로잉) | `src/art/hero.js` | 동작은 충분하지만 손으로 그린 스프라이트 시트보다 표정과 실루엣이 단순함 |
| 배경 시차 레이어 8종, 구름 | `src/art/background.js` | 사용 가능 |
| 지면, 시냇물, 풀 | `src/art/ground.js` | 사용 가능 |
| 천막, 상인, 제단, 게시판, 제재소와 물레방아, 고목, 바위 길, 등불, 바위, 버섯 | `src/art/props.js` | 사용 가능. 상인 NPC는 2프레임뿐인 임시 수준 |
| 아이템·도끼 아이콘 | `src/art/icons.js` | 도끼 45종이 같은 형태에 색만 다름. **교체 권장(임시)** |
| 비트맵 폰트 5×7 | `src/gfx/Font.js` | 영문 대문자와 숫자만. 한글은 HTML UI의 시스템 글꼴 사용 |
| 효과음, 환경음, 음악 | `src/audio/Audio.js` | Web Audio 합성. 녹음 소스보다 질감이 단순함. **음악은 임시 수준** |

## 교체가 필요한 임시 리소스

1. 도끼 45종의 개별 외형: 지금은 날 색상과 성급 반짝임만 다름
2. 상인 NPC 애니메이션
3. 음악: 생성형 패드와 멜로디. 지역 테마곡으로 바꿔야 함
4. 타격음 질감: 실제 나무 타격 녹음을 쓰면 크게 나아짐
