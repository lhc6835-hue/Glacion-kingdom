## 1. 정체성

| 항목 | 내용 |
|---|---|
| 제목 | 글래시온 왕국 — 깃털족의 노래 (Kingdom of Glacion) |
| 장르 | 오픈월드 판타지 탐험 RPG (HD-2D 탑다운) |
| 주민 | **깃털족** — 동글동글한 작은 새들. 오목눈이, 박새, 울새, 참새, 파랑새, 까마귀, 올빼미, 비둘기, 물총새, 방울새 |
| 주인공 | 파랑새 새내기 모험가. 걷고, 뛰고, 깡총 점프하고, **높은 곳에서 활공**한다 |
| 핵심 가치 | ① 압도적으로 아름다운 풍경 ② 제한 없는 탐험 ③ 오래 즐길 수 있는 깊은 콘텐츠 |

### 1.1 왜 HD-2D인가
- 모든 그래픽은 코드로 직접 그린 **2D 그림(스프라이트)**이다. 외부 에셋은 쓰지 않는다.
- 카메라는 절대 기울지 않고 항상 북쪽을 바라본다. 대신 렌즈를 아래로 밀어(off-axis frustum) 발밑 땅은 탑다운으로 보이고, 화면 위쪽에는 **실제 지평선과 하늘, 먼 산맥, 왕성**이 보인다.
- 수직으로 선 그림(나무, 건물, 캐릭터)은 화면과 평행하므로 원근 왜곡 없이 "그림 그대로" 보인다.
- 멀리 보이는 왕성과 산은 배경 사진이 아니다. 실제로 걸어가면 점점 커지는 월드의 일부다.

### 1.2 시각 규칙
- 빛은 **왼쪽 위(서쪽)**에서 온다. 모든 그림은 왼쪽 위가 밝고 오른쪽 아래가 차가운 그늘이다.
- 따뜻한 햇빛과 시원한 푸른 그늘의 대비. 네온색은 금지.
- 지붕은 붉은색, 주황빛 적색, 적갈색이 기본이다. 귀족 구역에는 청회색, 청록 지붕이 섞인다.
- 먼 것일수록 하늘색 대기 원근(haze)에 잠긴다.

## 2. 세계관

### 2.1 글래시온의 기원
- 「글래시온」은 고대어로 **빙하의 노래**라는 뜻이다. 북쪽 서리왕관 산의 빙하가 녹아 흐르는 물이 은빛 강, 왕관 수로, 청옥 호수를 이루고 왕국을 키웠다.
- 깃털족은 이 물에 **울림(Resonance)**이 깃들어 있다고 믿는다. 빙하수는 지나온 땅의 기억을 노래처럼 품고 흐른다.

### 2.2 역사 연표
| 시기 | 사건 |
|---|---|
| 약 1200년 전 | 서쪽 절벽 위에 **오스트미어 왕국**이 번성한다. 「노래하는 빙하수」로 하늘을 다스렸다고 전해진다 |
| 약 800년 전 | **침묵의 밤**. 노래가 끊기고 오스트미어는 하룻밤 사이에 잿빛으로 변한다. 잿빛 첨탑 요새만 남는다 |
| 약 760년 전 | 떠돌던 깃털족 무리가 동쪽 고원에 둥지를 튼다. 오목눈이 여왕 **세레니아 발크레스트**가 글래시온을 세운다 |
| 약 300년 전 | 협곡 대교가 놓여 서쪽 절벽과 왕도가 이어진다 |
| 현재 | 노왕 **아우렐 발크레스트**가 병석에 있다. 빙하가 줄어들고 폭포의 물소리가 약해진다. 협곡에서 이상한 메아리가 들린다 |

### 2.3 신앙과 마법
- **창공의 어머니 아우라**: 모든 바람이 언젠가 처음 불어온 곳으로 돌아간다는 믿음. 「바람은 돌아온다」는 작별 인사가 여기서 왔다.
- **울림 마법**: 깃털 하나하나가 특정한 음에 공명한다. 마법사는 바람, 물, 빛의 「음」을 맞춰 현상을 일으킨다. 4개 음계가 있다.
  - **서리음**: 빙하수의 기억. 얼림, 기억 읽기, 시간 지연
  - **햇음**: 생명과 성장. 치유, 식물, 빛
  - **폭풍음**: 바람과 이동. 활공 강화, 밀어내기, 번개
  - **별음**: 경계와 꿈. 은신, 소환, 방어막

### 2.4 세력
| 세력 | 설명 |
|---|---|
| 발크레스트 왕가 | 오목눈이 왕족. 왕위 계승 문제로 궁정이 둘로 갈려 있다 |
| 까마귀 경비대 | 성문과 성벽을 지키는 왕국 경비대. 무뚝뚝하지만 정직하다 |
| 바람깃 모험가 길드 | 의뢰를 중개하는 길드. 등급제(깃털 → 날개 → 하늘 → 별) |
| 장인 조합 | 대장장이, 약사, 재봉사들의 연합. 남서 장인 구역이 근거지 |
| 안개감시단 | 왕국 밖을 순찰하는 정찰대. 습지와 숲의 이변을 추적한다 |
| 침묵의 합창단 | 오스트미어의 노래를 되살리려는 비밀 결사. 폐허에 흔적을 남긴다 (메인 스토리의 핵심) |

## 3. 월드 구조 (2048m × 2048m, 셀 2m)

```
              (북) 서리왕관 산맥 — 화면 밖 원경 패널
      ┌──────────────────────────────────────────────┐
      │  은빛 협곡 ↓                                    │
      │ ┌─잿빛 절벽 고원(58m)─┐  ║  ┌─왕도 고원(56m)────┐  │
      │ │ 잿빛 첨탑 요새(폐허) ├══협곡 대교══┤ 왕성 암반(84m)  │  │
      │ │                    │  ║  │  왕도 (성벽 고리)   │  │
      │ └─계단 폭포 ─────────┘  ║  └─ 왕관 폭포 ──────┘  │ 동쪽 망루 언덕
      │            청옥 호수 (수면 0m)          ↘로우미어 강│
      │   햇살 언덕(시작)        남쪽 숲길 ↓              │
      │              노목의 숲 (남부 대삼림)                │
      └──────────────────────────────────────────────┘
```

| 지역 | 상태 | 특징 |
|---|---|---|
| 햇살 언덕 | ✅ | 시작 지점. 호수 너머로 왕성과 폭포가 한눈에 보인다 |
| 청옥 호수 | ✅ | 수면 반짝임, 얕은 물 색, 물가 거품. 헤엄칠 수 있다 |
| 왕관 폭포 · 면사포 폭포 | ✅ | 왕도 수로가 고원 남서쪽 절벽에서 호수로 떨어진다 |
| 계단 폭포 | ✅ | 잿빛 고원에서 세 단으로 떨어지는 숨은 폭포 |
| 협곡 어귀 폭포 | ✅ | 은빛 강이 협곡을 빠져나오며 떨어진다 |
| 글래시온 왕도 | 🔶 | 성벽 고리, 성문 3개, 9개 거리, 광장, 시설 16곳. 건물 내부는 미구현 |
| 발크레스트 왕성 | 🔶 | 암반 위 첨탑과 성관, 오르막, 정문. 내부는 ⬜ |
| 협곡 대교 | ✅ | 12경간 아치교. 위를 걸을 수 있다 |
| 잿빛 첨탑 요새 | 🔶 | 폐허 탑과 벽, 비석. 지하 던전은 ⬜ |
| 은빛 협곡 | 🔶 | 지형만 있음. 메아리 이벤트는 ⬜ |
| 노목의 숲 | 🔶 | 거대 숲 식생만 있음 |
| 동쪽 망루 언덕 · 불잎 고원 | 🔶 / ⬜ | 붉은 단풍 생태. 고원 본체는 다음 확장 |
| 안개 습지 · 서리왕관 설원 · 별빛 고지 · 해안 절벽 · 지하 동굴 | ⬜ | 월드 확장 단계에서 추가 |

## 4. 시스템 설계

### 4.1 이동 ✅
- 걷기 4.4 m/s, 달리기(Shift) 7.6 m/s, 깡총 점프, 수영(물에 동동 뜬다)
- **활공**: 공중에서 Space를 누르고 있으면 날개를 펴고 천천히 하강하며 9.5 m/s로 이동한다. 기력을 소모하고 착지하면 회복된다
- 절벽은 걸어서 오를 수 없다(높이 0.85m 초과). 대신 경사로, 오르막길, 다리로 연결된다. 절벽에서 뛰어내리는 것은 언제나 가능하다. 보이지 않는 벽은 없다

### 4.2 퀘스트 🔶
- 게시판 의뢰 12종 ✅: 탐험, 수집, 조사, 배달. 순서 제약 없음. 검색, 유형 필터, 정렬, 추적, 포기 가능
- 목표 유형 ✅: visit / talk / inspect / collect. 보고 NPC가 있으면 보고해야 완료된다
- ⬜ 다중 해결 경로 퀘스트, 실패 분기, 평판 연동, 연쇄 메인 스토리 「침묵의 합창」

### 4.3 직업 (⬜ 설계)
직업은 종족과 상관없이 고를 수 있다. 보조 전문화를 하나 더 익혀 혼합 빌드를 만들 수 있다.

| 직업 | 역할 | 고유 메커니즘 | 전투 리듬 |
|---|---|---|---|
| 깃검사 | 근접 기동 | **돌풍 게이지**: 이동 거리만큼 차오르고, 돌진 베기로 소모 | 빠른 연타, 뛰어들고 빠지기 |
| 둥지수호자 | 탱커 | **둥지 영역**: 바닥에 둥지를 펼쳐 안의 아군 피해 감소, 밖으로 나가면 해제 | 느리고 단단함, 자리 지키기 |
| 울림술사 | 원거리 마법 | **4음 화음**: 서리, 햇, 폭풍, 별 음을 순서대로 눌러 화음 주문 완성 (조합 24종) | 준비 → 폭발 |
| 바람사수 | 원거리 물리 | **바람 읽기**: 바람 방향과 세기에 따라 화살 궤적이 휜다 | 위치 선정, 정밀 |
| 그림자깃 | 은신·암살 | **달그림자**: 그늘, 밤, 덤불 속에서만 은신 유지 | 매복, 일격 |
| 약초술사 | 회복·지원 | **채집 연동**: 필드에서 캔 재료로 즉석 물약 투척 | 보조, 상태이상 |
| 폭풍부름 | 광역 마법 | **기압**: 높은 곳일수록 위력 상승, 낮은 곳에서는 약함 | 고지대 장악 |
| 사냥매 | 소환·조련 | **동료 맹금**: 작은 매를 지휘해 표식, 공격, 정찰 | 지휘, 협공 |
| 노래꾼 | 버프·디버프 | **리듬 연주**: 박자에 맞춰 입력하면 효과 증폭 | 리듬 액션 |
| 깃공예가 | 설치·제작 | **장치**: 덫, 포탑, 활공 발판 설치. 전투 밖에서도 탐험 보조 | 설계, 함정 |

- 성장: 레벨 → 특성 트리(직업별 3갈래) → 20레벨에 상위 전문화 2택 1 (예: 깃검사 → 폭풍칼날 / 은빛기사)
- 직업 변경: 신전에서 가능하다. 숙련도는 직업별로 따로 남는다

### 4.4 장비 (⬜ 설계)
| 계열 | 특징 | 사용 직업 |
|---|---|---|
| 깃칼 | 짧고 가벼움, 공중 공격 가능 | 깃검사, 그림자깃 |
| 날개검 | 양날 대검, 활공 중 내려찍기 | 깃검사, 둥지수호자 |
| 둥지방패 | 막기 성공 시 반격, 방패로 미끄러지기 | 둥지수호자 |
| 갈퀴창 | 긴 사거리, 땅에 꽂아 장대높이뛰기 | 둥지수호자, 사냥매 |
| 바람활 | 충전형, 바람 보정 | 바람사수 |
| 깃털다트 | 연사, 독·수면 코팅 | 그림자깃, 약초술사 |
| 울림지팡이 | 화음 슬롯 4개 | 울림술사, 폭풍부름 |
| 소리굽쇠 | 짧은 지팡이, 공명 폭발 | 울림술사, 노래꾼 |
| 류트·피리 | 연주 무기 | 노래꾼 |
| 공구벨트 | 장치 슬롯 | 깃공예가 |

- 희귀도: 평범 · 정교 · 명품 · 유물 · 전설. 유물 이상은 고유 외형과 획득 이야기를 가진다
- 재료: 청강석(은빛 강), 서리유리(빙하), 불잎섬유(불잎 고원), 오스트미어 유리(폐허), 달맞이이끼(호숫가)
- 강화는 대장간, 조합은 물약상, 감정은 고물상과 마법 상점에서 한다. 장비는 캐릭터 그림에 반영된다(모자, 목도리, 무기 그림)

### 4.5 생명체와 보스 (⬜ 설계)
| 이름 | 서식지 | 행동 |
|---|---|---|
| 도토리 다람쥐 | 숲 | 중립. 놀라면 도토리를 떨어뜨린다 |
| 이끼두꺼비 | 습지 | 매복. 혀로 끌어당긴다 |
| 가시고슴도치 무리 | 초원 | 무리 지어 굴러온다 |
| 물안개 정령 | 폭포 주변 | 물보라 속에서 나타나 밀어낸다 |
| 돌껍질 게 | 호숫가 | 단단함. 뒤집으면 약점 |
| 회색 족제비 도적단 | 길가 | 지능형. 포위하고 도주한다 |
| 잿빛 메아리 | 폐허 | 소리에 반응. 조용히 지나가면 피할 수 있다 |
| 불잎 여우 | 불잎 고원 | 불꽃 꼬리, 환영 분신 |

보스:
- **협곡의 메아리 「무명의 합창」**: 은빛 협곡 깊은 곳. 소리를 흉내 내 공격을 되돌린다. 음을 맞춰 침묵시켜야 한다
- **서리왕관의 거대 백로 「하얀 겨울」**: 설원 꼭대기. 활공 높이를 겨루는 공중전
- **불잎 고원의 「타오르는 꿩」**: 숨은 퀘스트로만 만난다. 쓰러뜨리지 않고 달래는 결말이 있다

### 4.6 NPC와 사회 🔶
- ✅ 이름, 역할, 생활 패턴(시설 운영 시간, 밤에는 귀가), 고유 대사, 가까이 가면 돌아보기
- ⬜ 관계와 평판, NPC끼리 대화, 사건 반응, 개별 일과 경로

### 4.7 생활 콘텐츠 (⬜ 설계)
채집 ✅(퀘스트용 아이템), 낚시, 요리(음식점 연동), 둥지 꾸미기(왕도 빈집 임대), 구름사슴 타기, 별자리 관측(별빛 고지), 경매

### 4.8 시간과 날씨
- ✅ 하루 = 실시간 24분. 새벽, 낮, 노을, 밤 팔레트가 바뀌고 별, 달, 창문 불빛, 가로등이 켜진다
- ✅ T 키로 시간 빠르게 흐르게 하기, 여관에서 쉬면 아침이 된다, 벤치에 앉으면 1시간이 지난다
- ⬜ 날씨: 비(젖은 땅 셰이더 값 `uWet` 준비됨), 안개, 눈(`uSnow` 준비됨), 강풍(`uWind`)

### 4.9 사운드 ✅ (절차 합성)
음원 파일 없이 Web Audio로 실시간 합성한다. 바람, 폭포(거리 감쇠), 새소리(낮, 숲 밀도), 풀벌레(밤), 하프 아르페지오와 패드 음악(들판, 왕도, 고지대, 밤 모드), 효과음.

## 5. 기술 구조

```
src/
  core/      Engine(렌더 루프) · CameraRig(off-axis 카메라) · Input · GameState(저장) · Quests
  world/     Layout(손으로 배치한 지리) · WorldData(셀 데이터 생성) · Ground · WaterView
             Decor(식생) · Town(왕도, 왕성, 다리, 폐허) · People(NPC) · Pickups · SkyView · DayNight · Collision
  art/       paint(붓 도구) · trees · architecture · characters(깃털족) · sky   ← 모든 그림을 코드로 그림
  gfx/       Look(공용 셰이더 값) · Atlas(텍스처 아틀라스) · Sprites(인스턴싱 빌보드, 그림자)
  data/      facilities · quests · townsfolk
  ui/        UI(DOM) · style.css
  audio/     Audio(절차 합성)
tools/       serve · shot(헤드리스 스크린샷) · smoke(자동 실행 테스트)
```

- **데이터 기반**: 지리는 `Layout.js`, 시설, 의뢰, 대사는 `data/`에 있다. 콘텐츠를 추가할 때 코드를 고칠 필요가 거의 없다
- **최적화**: 지면은 청크 단위 2단계 LOD를 쓰고, 스프라이트는 아틀라스 페이지당 인스턴싱 1 드로콜이다. 컷아웃 알파 + alpha-to-coverage를 쓴다
- **저장**: localStorage `glacion-save-v1`. 20초마다, 그리고 발견과 퀘스트 이벤트마다 자동 저장한다
