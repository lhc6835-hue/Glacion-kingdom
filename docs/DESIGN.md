# 기술 설계

## 스택 선택

- **Vite + 순수 ES 모듈 + Canvas 2D**: 저장소에는 이미 Vite 빌드, 헤드리스 점검, 단일 HTML 빌드, Pages 배포 도구가 있어서 그대로 이어 씁니다. 이전 게임이 쓰던 Three.js는 2D 횡스크롤에는 필요 없어서 뺐습니다
- 게임 엔진 대신 Canvas 2D를 고른 이유: 화면을 270px 높이의 저해상도로 그리면 스프라이트 수천 개를 그려도 가볍습니다. 정수 배율 확대가 쉽고, 빛 레이어를 따로 부드럽게 합성하기도 쉽습니다. 외부 런타임 의존성은 하나도 없습니다

## 렌더링 파이프라인 (`src/gfx/Renderer.js`, `src/core/Engine.js`)

1. **픽셀 캔버스**: 높이 약 270 아트 픽셀. 화면 높이에 맞춰 정수 배율(×2, ×3, ×4…)로 정하고, 가로는 화면비에 맞춰 늘립니다
   - 하늘: 1×22 그라디언트를 최근접 보간으로 늘려서 띠 모양 하늘을 만듭니다
   - 시차 레이어: 먼 봉우리 0.05 → 절벽과 폭포 0.12 → 먼 숲 0.2 → 중경 숲 0.35 → 근경 나무 기둥 0.6 → 지면 1.0 → 수관 천장 0.6 → 전경 고사리와 덩굴 1.15
   - 레이어마다 그린 뒤 그 시간대의 안개색을 반투명하게 한 번 덮습니다. 그래서 먼 것일수록 대비가 낮아집니다(대기 원근)
   - 월드: 지면, 소품, 나무, 생물, 주인공, 파티클, 앞쪽 풀
   - 색 보정: 시간대별 색으로 `multiply` 합성(그늘의 청록, 밤의 푸른색)
2. **빛 캔버스(2배 해상도, `screen` 합성, 부드러운 보간)**: 수관 틈(`canopy.gaps`)에서 떨어지는 빛줄기. 해 위치에 따라 기울기가 바뀌고, 3갈래로 나뉘어 따로 깜빡입니다. 바닥 빛무늬, 해·달 번짐, 등불, 모닥불, 룬, 이끼심장 핵, 화상 나무, 반딧불, 타격 섬광, 휘두르기 궤적, 지면 안개도 여기에 그립니다. 블룸은 미리 만든 방사형 빛 스프라이트로 대신하고, 발광체에만 씁니다
3. **UI 픽셀 캔버스**: 타이밍 바, 나무 HP 바, 피해 숫자, 판정 문구, 시네마틱 타이틀. 5×7 비트맵 폰트를 씁니다

픽셀 정렬: 논리 위치는 실수로 계산하고, 그릴 때만 반올림합니다. 수관 흔들림은 조각마다 1픽셀 단위로 움직여서 실루엣이 흐려지지 않습니다.

## 모듈

| 모듈 | 역할 |
|---|---|
| `data/*` | 등급, 도끼, 나무, 아이템, 클래스, 제재소, 밸런스 수치. 모든 수치가 여기 있음 |
| `game/GameState.js` | 저장되는 상태, 지갑·인벤토리 연산, 마이그레이션 |
| `game/AxeStats.js` | 도끼, 성급, 클래스를 하나의 보정값으로 합침. 상한 적용, 판정 구간 계산 |
| `game/Combat.js` | 마커, 클릭 판정, 휘두르기 상태 기계, 피해 계산, 상태 이상, 연쇄 번개, 공허, 클래스 기술 |
| `game/Trees.js` | 나무 인스턴스, 지속 피해 틱, 쓰러짐, 보상, 재생, 희귀종 등장 |
| `game/Economy.js` · `Gacha.js` · `Processing.js` | 판매·구매·강화·클래스 / 뽑기와 천장 / 제재소 |
| `game/SaveManager.js` | 임시 키에 쓰고 검증한 뒤 교체, 직전 저장본을 백업 |
| `game/Player.js` · `Cinematic.js` · `World.js` · `Game.js` | 이동과 포즈, 오프닝, 지역 배치, 전체 연결 |
| `gfx/*` · `art/*` · `audio/*` · `ui/*` | 렌더링, 절차적 픽셀 아트, 합성 사운드, HTML UI |

게임 로직(`data`, `game/GameState`·`AxeStats`·`Combat`·`Trees`·`Economy`·`Gacha`·`Processing`·`SaveManager`)은 DOM에 의존하지 않습니다. 그래서 Node에서 바로 테스트하고 시뮬레이션할 수 있습니다.

## 전투 규칙

- 판정: 바 0~1, 중앙 0.5 기준 반폭. 크리티컬 2.5%, 그레이트 7.5%, 굿 12%, 약함 20%(전체 폭으로는 5/15/24/40%)
- 피해 = 도끼 피해 × 판정 배율(3.0/1.7/1.25/0.75/0) × (1 + 콤보·상성·낮밤·처형·연속 크리티컬 보너스 합) × 기술 배율 → 방어 차감(최소 10%)
- 보정 상한: 구간 확장 +60%, 크리티컬 구간 +60%, 마커 감속 40%, 회복 단축 40%. 구간은 항상 크리티컬 ⊂ 그레이트 ⊂ 굿 ⊂ 약함으로 중첩
- 휘두르기: 들어 올림 0.09초 → 가속 0.06초 → 타격 → 후속 0.08초 → 회복 0.2초(가벼운 도끼는 짧아짐). 입력은 즉시 판정하고, 휘두르는 도중의 클릭은 버퍼에 저장
- 타격 정지는 월드 시간만 느리게 합니다. 마커는 계속 움직여서 리듬이 깨지지 않습니다

## 새 도끼 추가하기

`data/axes.js`에 항목 하나를 추가하면 끝입니다. 효과 타입이 기존 21종 안에 있으면 뽑기 풀, 도감, 가방, 아이콘, 전투에 자동으로 들어갑니다. 새 효과 타입이 필요하면 `AxeStats.computeMods`와 `Combat.resolve`에 구현하세요. 구현되지 않은 타입은 테스트가 실패로 잡아냅니다.
