## Axenfall v0.1 — 핵심 루프 (현재)

### 결정 사항
- 사용자 요청에 따라 저장소의 이전 게임(글래시온 왕국, Three.js 탑다운)을 걷어내고 Axenfall로 교체했습니다. 이전 코드는 git 기록에 남아 있습니다(`66d243c` 이전)
- 색감: 맑고 산뜻한 쪽이 아니라 **그늘진 계곡 숲**입니다. 청록 그림자, 이끼 바위, 시냇물에 따뜻한 빛줄기로 대비를 줬습니다
- 에셋: 외부 무료 에셋을 우선하기로 했지만 네트워크 정책으로 사이트가 막혀서, 전부 코드로 생성했습니다([ASSETS.md](ASSETS.md))
- 1차 범위: 핵심 루프를 완성하는 것. 지역 1곳, 전투, 경제, 뽑기, 제재소, 클래스, 저장, 오프닝까지
- 첫 지역 이름은 프롬프트의 Evergreen Haven을 계곡 콘셉트에 맞춰 Evergreen Hollow(상록 계곡)로 바꿨습니다

### 검증
- `node tests/logic.mjs`: 55/55. 데이터 무결성, 판정 구간, 판정별 피해, 방어, 화상, 연쇄 번개, 공허, 클래스 효과, 판매와 구매, 뽑기 확률과 천장, 제재소, 오프라인 상한, 시계 되돌림, 저장과 백업 복구, 마이그레이션
- `node tests/smoke.mjs`(빌드 후): 25/25. 실제 브라우저에서 타이틀, 시네마틱 건너뛰기, 이동, 클릭으로 벌목, 크리티컬 3배, 빗나감, 나무 쓰러짐, E로 상인 열기, 판매, 도끼 구매와 장착, 10회 기도, 제재소 수리와 가공, 클래스 구매, Q 기술, 밤, 새로고침 후 진행 유지, 헤드리스 60fps, 런타임 오류 없음
- `node tests/balance.mjs`: 결과는 [BALANCE.md](BALANCE.md)
